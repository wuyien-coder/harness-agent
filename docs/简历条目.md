# 可改写到简历的项目条目

**面向领域知识库的 GraphRAG 智能问答平台｜学位论文工程化重构 / 个人项目**

技术：Python、FastAPI、LangGraph、PostgreSQL、pgvector、Redis、Celery、React、TypeScript、Docker Compose

## 三行版

- 基于 FastAPI、React/TypeScript 将论文知识问答重构为领域知识平台，接入 326 份传记、9,921 个文本块及 335 节点关系图谱，实现多轮会话、真实 SSE 输出与可追溯引用。
- 使用本地 BGE 与 BM25 双路召回，提供加权融合 / RRF 消融，通过 LangGraph 实现 ReAct 工具决策循环，根据观察结果自主补查文本与图谱，完成生成与引用检查。
- 落地 PostgreSQL/pgvector HNSW、Redis 检索缓存与 Celery 异步摄取，通过索引版本处理跨进程更新；完成 84 项自动化测试及真实模型、上传检索、移动端验收。

## 半页版

- 按 API、业务服务、Agent、检索与存储分层，将研究代码转化为支持问答、会话管理、引用查看、TXT/Markdown/PDF 上传与任务追踪的应用。
- 基于章节和句子分块，保留人物、章节、页码等元数据；使用真实 BGE-small-zh-v1.5 生成 512 维向量，并以内容寻址缓存复用已编码文本。
- 采用稠密检索与 BM25 混合召回，默认加权融合，支持 RRF 与精排扩展；以关系表和 NetworkX 提供师承、路径及领域查询，将文本与图谱证据装配为带引用编号的上下文。
- 使用 LangGraph 实现 ReAct 决策、工具执行和观察循环，支持模型自主选择只读工具、根据结果补查以及有界终止；SSE 先返回证据，再转发真实模型增量，逐轮记录 token 用量。
- 接入 PostgreSQL/pgvector、Redis 和 Celery，持久化任务状态并使用索引版本刷新 API 快照与缓存；配套 Alembic、Compose、Nginx 和自动化验证。

## 可核验结果（2026-10-17）

- 全量 326 份文档、9,921 块、335 图谱节点、355 关系；文本覆盖 265 个去重人物名，统计范围与图谱不同。
- 84 项测试通过、0 跳过，包括本机真实 pgvector 测试。
- 真实模型流式回答、引用、用量、Redis 命中、LangGraph 关系问题、Celery 摄取及索引删除实际验收通过。
- 桌面和手机页面通过浏览器验收，构建成功；停止 / 重启完整栈通过。

证据：reports/validation.json、tests-react.xml、full_validation.json、browser_full_validation.json。单次问答耗时仅是本机单次样本，不能改写为 p95、吞吐或性能提升；旧 eval_current.json 是 hash 离线样例结果。

ReAct 实测见 reports/react_validation.json 和 browser_react_validation.json，含连续人物查询及图谱无结果后补查原文的记录。

本项目为个人作品，按本人真实参与范围和日期填写。Docker Compose 已提供，本机没有 Docker，未声称容器联调或生产上线；精排默认关闭，引用编号检查也不等于逐句事实核验。没有用户账户、多租户、生产流量或训练/微调大模型。
